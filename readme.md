# Cpu assembler 
Written in python for my 8-Bit CPU project.
After designing my 8-Bit CPU it was too hard to write machine code for every program so I made this assembler to make it easier to program my CPU.


## Instructions to run

- Download all the files
- All the instructions are in the instr.txt file
- write your code in the code.txt
- run python3 main.py and follow the instructions in their
- After running it, open code.asm to see you compiled code.
